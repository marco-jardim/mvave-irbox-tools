# Example IRs: voice effects

Generated by `scripts/make_voice_irs.py`. They are original designs, not
captures, and are MIT-licensed like the rest of the repo. Each file is
2048 samples, 44.1 kHz, 24-bit mono, minimum-phase (no added latency),
with peak gain +6 dB.

| File | Character | Approx. passband |
|---|---|---|
| `voice_telephone.wav` | Telephone handset | 300 Hz – 3.4 kHz, +3 dB at 1.8 kHz |
| `voice_am_radio.wav` | AM radio speaker | 180 Hz – 4.5 kHz, +4 dB at 1.1 kHz |
| `voice_megaphone.wav` | Bullhorn | 600 Hz – 3.2 kHz, +8 dB at 1.4 kHz, horn reflections at 0.9 / 2.1 ms |
| `voice_walkie_talkie.wav` | Two-way radio | 450 Hz – 2.6 kHz, narrow +5 dB at 1.8 kHz |
| `voice_gramophone.wav` | Acoustic horn gramophone | 250 Hz – 5 kHz, resonances at 700 Hz and 2.5 kHz |

Load one to try it without saving:

```
uv run python scripts/irbox_tool.py ir-load examples/irs/voice_telephone.wav --normalize none
```

Or save it to a slot (`--normalize none` keeps the designed gain):

```
uv run python scripts/irbox_tool.py ir-upload examples/irs/voice_megaphone.wav --slot 3 --name "Megaphone" --normalize none --yes
```

Notes:

- The IR Box input is a 1 MΩ instrument input. A dynamic mic works, but it is
  quiet and noisy; use a mic preamp in front for vocals.
- These are linear filters only. Real radios and phones also distort; put a
  drive pedal before the IR Box for that.
- USB playback is not processed by the IR, so test with something plugged into
  the 1/4" input.
- Narrow-band IRs sound much quieter than full-range cabs at the same volume
  setting, so raise the preset volume (`volume`) if needed.
